# Pratik Gholap - Public Profile Portfolio

A mobile-responsive static portfolio built with HTML, CSS and JavaScript.

## Included
- Responsive desktop/tablet/mobile design
- Professional hero/profile section
- About section
- Social Work / Public Life / Business / Youth Entrepreneurship cards
- Photo gallery with click-to-enlarge lightbox
- Mobile navigation menu
- Smooth scrolling and scroll reveal animation
- Email and Instagram contact buttons
- Enhanced portfolio photos

## Run
Just open `index.html` in Chrome/Edge.

No backend or installation is required.

## Edit
- Personal text: `index.html`
- Design: `style.css`
- Interactions: `script.js`
- Photos: `images/`
